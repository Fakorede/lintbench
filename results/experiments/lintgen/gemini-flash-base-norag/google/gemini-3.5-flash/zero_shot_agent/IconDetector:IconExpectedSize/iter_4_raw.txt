To fix the compilation error, we need to understand how to get the `ResourceFolderType` from a `ResourceContext` or the file path.
In Android Lint, `ResourceContext` does not have `getFolderType()`. Instead, we can get the `ResourceFolderType` using `context.getClient().getResourceFolderType(context.file)` or simply parsing the parent folder name, or using `ResourceFolderType.getFolderType(context.file.getParentFile().getName())`.
Actually, `context.getClient().getResourceFolderType(context.file)` is the standard way, or `context.getFolderType()` is available in some versions, but since it failed, we can use `ResourceFolderType.getFolderType(file.getParentFile().getName())` or `context.getClient().getResourceFolderType(file)`.
Let's check if `context.getClient().getResourceFolderType(File)` exists. Yes, `LintClient.getResourceFolderType(File)` is a standard API.
Alternatively, we can use `ResourceFolderType.getFolderType(parentFile.getName())`. Let's check if `ResourceFolderType` has `getFolderType(String)`. Yes, `ResourceFolderType.getFolderType(String)` is a static method in `com.android.resources.ResourceFolderType`.

package com.android.tools.lint.checks;

import com.android.resources.ResourceFolderType;
import com.android.tools.lint.detector.api.Category;
import com.android.tools.lint.detector.api.Detector;
import com.android.tools.lint.detector.api.Implementation;
import com.android.tools.lint.detector.api.Issue;

import com.android.tools.lint.detector.api.Scope;
import com.android.tools.lint.detector.api.Severity;

    public static final Issue ISSUE = Issue.create(

            Category.ICONS,
            5,
            Severity.WARNING,
            new Implementation(
                    IconDetector.class,
                    Scope.RESOURCE_FILE_SCOPE

    @Override
    public void checkBinaryResource(ResourceContext context) {
        File file = context.file;
        if (file == null || !file.exists()) {
            return;
        }

        File parentFile = file.getParentFile();
        if (parentFile == null) {
            return;
        }
        String folderName = parentFile.getName();
        ResourceFolderType folderType = ResourceFolderType.getFolderType(folderName);
        if (folderType != ResourceFolderType.MIPMAP && folderType != ResourceFolderType.DRAWABLE) {
            return;
        }

        String name = file.getName().toLowerCase();
        if (name.endsWith(".png") || name.endsWith(".jpg") || name.endsWith(".jpeg") || name.endsWith(".webp")) {
            boolean isLauncher = name.startsWith("ic_launcher");
            boolean isMipmap = folderName.startsWith("mipmap");

            if (isLauncher || isMipmap) {
                checkImageSize(context, file, folderName);
            }
        }
    }
