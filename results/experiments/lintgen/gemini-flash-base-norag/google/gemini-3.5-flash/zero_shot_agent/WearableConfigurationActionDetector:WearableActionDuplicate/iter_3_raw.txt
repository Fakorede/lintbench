Wait, is `getElementsByTagName` recursive?
Yes, it returns all descendants.
But wait!
If we call `manifest.getElements("service")`, it returns all `<service>` elements in the manifest.
If we call `service.getElements("meta-data")`, it returns all `<meta-data>` elements inside that `<service>`.
But wait! What if a `<service>` has another `<service>` inside it? (Not possible in Android manifests).
What if a `<service>` has an `<activity>` inside it? (Not possible).
What if an `<activity>` has a `<meta-data>` inside it?
If we call `manifest.getElements("meta-data")`, it would return all `<meta-data>` elements in the manifest, including those inside `<service>`, `<activity>`, and `<application>`.
But we only call `service.getElements("meta-data")` on a `<service>` element, so it only returns `<meta-data>` elements inside that `<service>`.
